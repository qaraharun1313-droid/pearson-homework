# Pearson Homework Maker

A simple, responsive English homework worksheet maker.

## Features

- Multiple choice, fill-in-the-blank, short answer, and matching questions
- Grade and subject controls
- Printable worksheet layout
- Save as PDF using the browser print dialog
- Answer key
- Runs entirely in the browser

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
